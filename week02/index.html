Fluid Typography Explanation

The main heading uses:

clamp(1.75rem, 1.31rem + 1.88vw, 3rem)

The minimum font size is 1.75rem for small screens. The maximum font size is 3rem for desktop displays. The middle value combines rem and viewport width so the typography scales smoothly while remaining accessible when users zoom their browser to 200%.
